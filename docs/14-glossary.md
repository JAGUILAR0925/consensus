# 14. Glosario

| Término | Definición en Consensus |
| --- | --- |
| Administrador | Identidad de prueba autorizada para configurar y cambiar estados. |
| Auditoría | Reproducción de verificaciones mediante evidencia disponible. |
| Autorización | Prueba de que una identidad aprobó una operación. |
| Blockchain | Registro distribuido mantenido por una red bajo reglas compartidas. |
| Candidato u opción | Alternativa ficticia disponible en la elección. |
| Confirmación | Estado en el que la red acepta una operación. |
| Contrato inteligente | Programa desplegado que ejecuta reglas en la red. |
| Dirección | Identificador público de una cuenta o identidad en Stellar. |
| Elección | Agregado de configuración, opciones, participantes, estado y conteo. |
| Elegibilidad | Condición que permite participar en el escenario. |
| Evidencia | Dato reproducible que respalda una afirmación o resultado. |
| Mainnet | Red pública donde se utilizan activos reales. Fuera del MVP. |
| MVP | Implementación mínima para demostrar los objetivos educativos. |
| Operación | Acción incluida en una transacción de Stellar. |
| Red de pruebas | Entorno sin activos reales utilizado para desarrollo. |
| Stellar | Red blockchain seleccionada para el proyecto. |
| Testnet | Red pública de pruebas de Stellar. |
| Transacción | Contenedor firmado que envía una o más operaciones a la red. |
| TypeScript | Lenguaje confirmado para aplicación, scripts e integración. |
| Verificabilidad | Capacidad de comprobar propiedades del proceso mediante evidencia. |
| Voto aceptado | Operación que cumple autorización, elegibilidad, estado y unicidad. |
| Voto secreto | Propiedad que impide relacionar votante y elección. No garantizada por el MVP. |
